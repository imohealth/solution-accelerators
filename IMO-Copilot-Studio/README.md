# IMO Copilot Studio

## Features

- Connect a Microsoft Copilot Studio-built AI agent to the IMO MCP Server for diagnostic specificity workflows
- Utilize the IMO MCP server for any downstream clinical/revenue cycle/medical coding workflows
- Deploy and orchestrate MCP-enabled tools within low code Microsoft Copilot agent applications
- Extend clinical documentation and coding workflows with agentic AI experiences that are clinically grounded by IMO's rich terminology
